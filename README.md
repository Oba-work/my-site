# 🚀 About

**my-site (by Oba)** is a personal website created to showcase who I am, what I enjoy, and the projects I have worked on.

The website is built using the core technologies that power the web:

* HTML
* CSS
* JavaScript

The project is more than just a collection of webpages.

It is also a long-term learning project.

Every new feature provides an opportunity to learn something new about web development, programming, design, and problem solving.

The website is designed to grow over time.

New pages can be added.

Existing pages can be redesigned.

New projects can be showcased.

New functionality can be introduced.

The project is never required to stay exactly the same.

# 🌙 Dark Mode

Dark mode is powered by JavaScript.

The basic process is:

```text
User clicks the dark mode button
            ↓
JavaScript detects the event
            ↓
The theme changes
            ↓
The website updates
```

The important part is making sure that everything remains readable.

Dark mode therefore involves more than changing the page background.

Cards, text, buttons, borders, and other elements also need to work with the darker theme.

# 🖼️ Interactive Logo Viewer

The logo viewer is an example of turning a normal HTML image into an interactive feature.

A normal image could simply be:

```html
<img src="logo.png" alt="OBA Logo">
```

JavaScript can then add behaviour around that image.

The process becomes:

```text
Click logo
   ↓
JavaScript detects click
   ↓
Viewer opens
   ↓
Larger logo appears
   ↓
User closes viewer
   ↓
Normal page returns
```

This feature has been useful for learning about:

* Event listeners
* DOM manipulation
* Modals
* Keyboard events
* CSS positioning
* Image sizing

# 🎨 Colour System

The website uses CSS variables to keep important colours consistent.

One of the main project colours is:

```text
#1b1b2f
```

The stylesheet can store important colours centrally.

For example:

```css
:root {
    --ink: #1b1b2f;
    --paper: #fdfdfb;
    --brand: #92cffe;
    --brand-soft: #efeafc;
    --card: #ffffff;
}
```

This makes the CSS easier to maintain.

If a colour needs to change, the main variable can be updated instead of searching through the entire stylesheet.
